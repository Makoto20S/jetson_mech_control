# PH-EXO 电脑端调参工具

Windows 双击仓库根目录的 `Open-NX-Debug.cmd` 即可打开 NX 独立实机调参面板。重复双击会打开同一服务。首次启动时保留命令窗口，待面板确认停止后可关闭。点击“开始本轮”才通过项目的 SSH 配置连接 Orin。

**运动学跟踪**是默认视图。ψ、β 两图对照控制器参考角和状态链正解角；104、105 两图对照同一参考位姿对应的逆解编码器角和编码器反馈。逆解映射为 104＝α₂＋45°、105＝α₁＋45°。四图共用秒轴，单位为度，标题中的误差为同一状态快照的参考减反馈。编码器曲线优先使用反馈采样时间，缺少该时间的 ROS 记录使用状态观察时间。无有效反馈时曲线留空。点击「电机监测」可切回扭矩、速度和位置六图。

启动前可填**预览起点 ψ、β**（默认均为 0°），沿用左栏的目标、幅度、周期和波形，点「预览规划」。电脑端使用工程轨迹发生器和 REF-01 逆解画出过渡及一个最慢活动轴周期；正弦另含一个渐入周期，预览起点只用于画图。实际开始时沿用原有的现场启动姿态和力矩阻抗控制。点「返回跟踪」或导入本地 result.json 可查看实测对照。CSV 包含四组目标、反馈与编码器时间。更新前已打开的面板服务需待本轮结束后关闭并重新打开。

同一个页面提供两个正式入口，在仓库根目录执行：

| 用途 | 命令 | Orin 前置条件 |
|---|---|---|
| 接入完整 ROS 系统、查看状态与波形、设置下一轮阻抗参数 | `./tools/bench_panel/Open-Ros.ps1` | 已运行上层、状态和底层控制节点 |
| 独立台架调参 | `./tools/bench_panel/Open-Bench.ps1` | 已安装控制运行环境；无需预先启动上层 |

两个入口共用页面、曲线和现有原生阻抗控制器。独立入口通过原 worker 创建本轮专用底层控制，
仍依赖 Orin 的 ROS 运行库，但不调用上层接口。原终端脚本保留作为对照。

- 打开页面不自动连接或启动；当前候选 K=20、B=0.3。参数在开始前设置，运行中暂不修改增益。
- ROS 入口先“连接 ROS”只读状态；开始、停止、急停、返回调试调用既有上层服务。
- 独立入口点击开始才创建本轮底层；停止并核验退出后可重新设置。两个入口不要同时控制同一机构。
- 两者均可随时“返回调试”刷新页面；实际停止确认在后台保留，未确认时不能开始下一轮。
- 仅看界面加 `-Preview`。独立入口加 `-Software` 会使用私有模拟串口；
  ROS 入口加 `-Software` 只拒绝实机后端，不自动创建仿真系统。
- 通用入口 `Open-Bench-Panel.ps1 -Mode ros|bench` 默认 ros；旧 `-Legacy` 兼容为 bench。
- 页面、HTTP 服务和数据在电脑；Orin 仅保留接口、ROS 控制和通信。
- `data/runs/<编号>/` 不进 Git、不部署、不自动读取；仅显式“打开结果”或 `-Result <文件>` 读取。
  独立入口自动核验回传 `remote_raw`；断线遗留记录用 `collect.py <具体编号>` 回收。

完整说明见[调参面板说明](../../docs/parallel_exo/bench_panel.md)，
双入口软件证据见验证报告（项目本地记录 panel_dual_entry_20261114.md）。
软件联动工具：`test_ros_link.py`（ROS 系统），`test_bench_link.py`（独立台架）。

独立入口增加可填写幅度/周期的两轴连续往返；幅度留空保留固定模式。详见[连续往返说明](../../docs/parallel_exo/bench_panel.md#连续往返2026-11-17)。软件测试：`test_roundtrip_link.py reset` / `test_roundtrip_link.py estop`；两者强制私有PTY，禁止物理端口。


### 连续参考（2026-11-17）

ROS与独立入口均支持目标、两轴有符号幅度和完整周期；共用正式包
`mech_assist_control.robot.ph_exo_reference`。ROS模式配置/启动参见
`../../docs/parallel_exo/upper_impedance.md`。参考参数仅在每次开始时提交，
默认K20/B0.3，启动仍由操作者点击；打开页面不使能电机。
