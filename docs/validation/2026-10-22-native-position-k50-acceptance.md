# 原生MIT Kp50加力空载位置验收

任务：EXO-ARCH-001；日期：2026-10-22。
用户要求推进完整验收并允许加力，随后当次确认本篇完整包络、离体固定空载、无人体连接，
/dev/ttyACM1接线、板版本、CAN速率、方向与单位不变，现场全程可立即断电。
本轮范围是两轴逐轴及同时的小幅位置功能验收，不代表穿戴或全部硬件故障注入验收。

## 依据与参数

[上一轮原生Kp30复测](2026-10-22-native-position-restore.md)返回残差0.024033rad。
重新检查该记录，偏移和返回最后1秒的编码器位置范围均为0，
反馈力矩中位数分别+0.649573／−0.745299N·m。提高保护阈值本身不会增加同样位置误差下的PD输出，
因此本次提高Kp；不能由上述数据唯一认定摩擦，也不能保证加力后准确返回。

| 项目 | 本次值 |
|---|---|
| 模式／实现 | 原生MIT position；PositionCommandController；主机阻抗已移除 |
| Kp／Kd | 50N·m/rad／4N·m·s/rad，零速度参考和力矩前馈 |
| 反馈力矩保护 | 4N·m；不是硬力矩限流 |
| 名义PD配置预算 | 50×0.055+4×0.2=3.55N·m≤4N·m |
| 位置目标／参考斜率 | 新原点+0.05rad／0.015rad/s |
| 阶段与顺序 | 每组原位1s→偏移6s→返回6s；先1号、再2号，两者通过才同时运行，最多39s |
| 下层保护 | 反馈速度0.2rad/s、每轴新原点±0.2rad、目标偏差0.055rad |
| 到位／返回验收 | 每阶段最后0.5s所有记录位置误差≤0.005rad、速度≤0.05rad/s |
| 其他 | 原位校验、租约、反馈期限、故障联停不放宽；不改寄存器、不自动升级或重试 |

位置验收失败时，在未触发安全保护的情况下执行原计划返回，失能后结束，不进入后续组。
安全保护触发则立即停组，不继续返回动作。两轴与同时组全部通过、最终独立查两台失能才判本轮通过。
临时脚本和配置位于仓库外`native_position_k50_acceptance/`，不修改生产控制实现或默认参数。
已做6项端点检查，覆盖两轴到位／误差／未停稳／历史返回残差／观察窗口不足，及原生参数和预算断言。
完整软件回归沿用本次未变更的构建385项通过记录；本轮不重复全套测试。
