# EXO-ARCH-001 抗阻短脉冲抖动修正

## 问题与证据

前一轮双DM4310的20秒实机确认两台使能，但操作者反馈阻力不足、抖动明显。
[原始台架记录](2026-10-22-resistance-fast-bench.md)显示发送约500Hz、最大间隔2.39ms，
力矩反复成为约15–16ms的短脉冲，速度也在短周期内正反摆动。
主机频率没有明显断档；驱动器内部环频率未测量，不能据此排除电机或机械因素。

旧控制器在每次原始速度进入停止区或反向时清空速度滤波器和力矩，
下一次启动又按斜率建立力矩。较大阻尼与这种切换可能相互作用，不能仅加大B。

## 修改范围

- 通用C++控制器增加20ms同方向运动确认，按实际dt累计；静止和反向重新确认。
- 低通在有效许可期间持续更新，短时停顿不清空观察器；滤波方向与原始速度不同则不出力。
- 低速区连续衰减，阻力不超过当前原始速度对应的粘性幅值，减少滞后滤波的残留力矩。
- 保留立即静止/反向撤力、命令上限、方向角度软区、越界、许可TTL、租约、失联及运行时限保护。

未改变Python默认抗阻路径、厂商codec、电机寄存器、CAN速率或驱动器内部控制参数。
DM4310快环启动配置明确指定方向确认20ms；通用控制器同名参数默认20ms，合法范围[0,100]ms。
允许0用于关闭确认计时，但仍保留反向至少一周期零输出及方向检查。

## 实际C++回放

新增`resistance_controller_replay`测试工具，直接借用状态/命令接口调用生产控制器。
Python准备工具`tools/validation/replay_resistance_chatter.py`把历史反馈按2ms采样保持重采样，
仅使用采样时刻之前的记录；相同输入分别运行修改前和修改后的C++实现。
每轴9997行，B24、建立40N·m/s、上限8N·m、低通25ms不变。
回放位置范围是离线夹具值，不能作为真实机构部署范围。

| 固定输入指标 | 1号修改前→后 | 2号修改前→后 |
|---|---:|---:|
| 单步变化超过0.25N·m次数 | 114→13 | 104→1 |
| 总绝对力矩变化N·m | 153.12→22.74 | 132.80→6.40 |
| 最大单步变化N·m | 1.44→0.80 | 0.96→0.32 |
| 平均绝对命令N·m | 0.04040→0.00358 | 0.03038→0.00051 |

总变化减少约85%/95%，但平均阻力也明显降低：新算法主动拒绝这些短促摆动，
不能把减少脉冲等同于真实训练的阻力提升。持续0.3rad/s同向输入的独立测试仍达到
B24对应的7.2N·m稳态值，未整体削减阻尼系数。
所有回放样本命令幅值≤8N·m、与同一采样速度乘积≤0；
这只是离散命令方向检查，不证明连续时间机械被动性、驱动器实际力矩或人体安全。

回放在固定历史轨迹上进行，新的力矩不会改变输入速度，不能预测新闭环运动或手感。
旧回放也不是原始TX的逐帧重现：反馈接收时间与控制器内部读取时刻不同，重采样存在差异。

本地证据：`/home/nvidia/mech_attitude_validation/resistance_chatter_baseline/`、
`/home/nvidia/mech_attitude_validation/resistance_chatter_candidate/`。
包含输入、旧/新实际控制器输出、summary.json及人工检查的comparison.png；原始采集不改写。

复现示例（source覆盖层后，先构建mech_controllers测试目标；目录必须不存在）：

```bash
python3 tools/validation/replay_resistance_chatter.py \
  --input-dir /absolute/original-bench-evidence \
  --output-dir /absolute/new-replay-evidence \
  --probe /absolute/build/mech_controllers/resistance_controller_replay
```

修改前基线须由修改前二进制生成，工具不会假装恢复历史版本。

## 修正后首次20秒实机

用户要求“进行实机测试”，沿用已确认离体固定、无人体连接、现场可立即断电及
既有接线/板版本/CAN/方向单位条件。B24、建立40N·m/s、8N·m命令及反馈阈值、
20ms方向确认、25ms滤波、20秒窗口、实测绝对范围及失联保护保持；
没有1rad/s训练停机门限，相对位移限制仍关闭，有限协议解码范围50rad/s保留。
未改寄存器、未重试或自动加力。

只读18/18参数匹配，两台status0、位置0.118448/−1.116770rad。
确认广播器active后激活硬件，两台均回报status1，然后进入训练并提示操作者。
完整20秒结束、无运行时故障：30997次观察、10047行反馈且无溢出。
峰值反馈速度1.819292/0.451770rad/s，峰值反馈力矩1.316239/0.295482N·m。
两轴各9998条MIT力矩命令，500.053Hz，最大间隔2.093/2.114ms，无超过4ms间隔；
Kp/Kd均0，编码力矩峰值1.604396/0.642247N·m，无命令接近8N·m。

操作者反馈“这个力矩感觉没有提升”，阻力效果仍不通过；
本轮未取得明确的抖动改善确认，不能把无故障运行当作手感验收。
不同轮次动作与速度不同，不能把跨轮峰值或突变总次数直接当作修正效果的受控比较。
