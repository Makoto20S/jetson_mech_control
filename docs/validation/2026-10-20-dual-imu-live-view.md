# 双 IMU 真实数据只读显示验证

## 范围

2026-10-20，Jetson Ubuntu / ROS 2 Humble，本地分支
`codex/jetson-dual-imu-attitude`，基于 `f099efd` 的未提交姿态及可视化改动。
用户明确授权真实双 IMU 只读显示，并说明传感器目前在桌面。
没有执行站立零位、动作轴标定或电机控制，不将桌面姿态解释为人体膝角。

## 接入与检查

- 当前 USB 身份与既有通道资料核对，使用 `/dev/ttyACM0`。
- 启动前端口无其他持有者；用户在本机给予该节点临时 ACL 权限。
- 从当前源码构建接收桥及依赖，独立构建姿态/显示包。
- 接收桥只配置固定 USB 接收转发，不发送应用 CAN 帧；没有启动电机节点。
- 使用隔离 ROS 域 69 和 localhost，真实 bridge → IMU → 姿态节点 → Tk 只读界面。

## 边界与下一步

这是实时接收、姿态发布和 GUI 显示验证，不是姿态精度、绝对航向、
硬件同步或解剖学角度验收。旧遥测无每颗 IMU 的独立采样计数器，
不能证明包持续到达时某一颗 IMU 未冻结。

下一步是在 I1/I2 正确固定到大腿/小腿后重新执行静态→动作轴→静态标定，
并用独立同步角度参考检查膝角；不得沿用桌面姿态作为站立零位。
