# PH-EXO：20 ms反馈下的固定姿态阻抗软件验证

本页记录早期显式软件验证入口。2026-11-12 已将连续时间异步预测候选接入现有 ROS 控制器，需显式 --predictive 才启用，默认仍为普通阻抗。当前部署、未达标项与终端入口见[预测阻抗实机候选说明](predictive_bench.md)。本页历史数值结果不能替代该候选的验收。

## 控制路径

量化反馈 → 原生MuJoCo正解、速度、投影惯量 → 原始Session有效期/序列检查 → 5 ms中点预测阻抗 → 双轴共同限幅 → KinematicCommandLease → Direct台架力矩通道 → 工程原MIT编码器/反量化 → MuJoCo物理模型。

新核心为ref01_bench_predictor.hpp；Ref01Model.mass为约束投影N.T M N。没有改动MJCF质量、摩擦、零位或β范围。控制器核心不依赖厂商codec；软件验证程序在适配层编码后，把实际编码目标传入预测器。该字段不是测得的轴端力矩。

名义K为两轴10 N·m/rad，B为两轴1 N·m·s/rad。用户允许调整B，但当前通过的候选保留B=1。每轴5 N·m、5 A、相对启动±30°、最长30 s仍在台架通道中。Direct策略最初仅在本软件入口选择；2026-11-11按用户要求，实机台架插件也显式选择Direct，取消0.5 N·m/s斜率。该输出策略变更不启用本页预测器或自适应候选；LegacyRamp仅保留历史对照能力。

中点计算使用h=0.005 s：H = M + h/2 B + h²/4 K，a = H^-1 [K(e-hv/2)-Bv+f_est]。中点误差为e-hv/2-h²a/4，速度为v+ha/2。力矩仍由g+K e_mid-B v_mid经A.T分配。扰动估计用于状态预测，未作为外力补偿直接叠加到目标。量化区间外的速度残差更新估计，增益1-0.75^(sample_dt/0.020)。半LSB测量区间对应本仿真四舍五入方式；实际固件取整仍未独立确认。

## 运行

Windows从仓库根目录：

    .local\venv\Scripts\python.exe -B tools/project/verify_ref01_sampled_bench.py --output <新的本地输出目录>

Orin从开发副本使用其MuJoCo环境：

    .local/venv/bin/python -B tools/project/verify_ref01_sampled_bench.py --output .local/validation/<新目录>

默认运行两个姿态下的双轴正负0.3 N·m扰动、30 s静止保持、恒载/撤载及五类故障。源反馈每20 ms更新，编码器0.1°、速度10 ERPM量化；5 ms控制更新；MIT原有12 bit、±15 N·m截断编码保持。仿真无附加传输延迟，两轴反馈同步。

从2.5 s起持续满足双轴误差≤0.5°、速度≤1°/s；恒载试验从撤载后1.5 s起检查。恒载静偏转另与0.3/10 rad比较，防止用实际降低静刚度获得假通过。预测不改变源反馈时间；断流、计划过期、关闭、序列倒退、同序列数据突变须锁存，一次名义零撤销后停止写入，恢复反馈不能自动重启。输出目录必须新建，结果与报告只归档Windows。

## 与真实ROS控制链的边界

本入口使用既有C++模型、Session、命令租约、台架包络和MIT编解码，但不运行controller_manager或真实硬件插件。这是当时的集成边界；2026-11-12 的显式预测候选已接入，详见上述当前入口。

接到异步ROS/串口链之前，需要硬件适配层提供带发送时间/代次的实际发送目标回执，并按原始反馈时刻校正和重放历史预测，处理两轴反馈错相；不能把当前请求当已发送，也不能把滞后测量当当前状态。后续集成使用同一核心，补测这些时序情形后再切换实机入口。当前模型未独立验收转子惯量、摩擦和实际轴端力矩，本软件结果不证明实机稳定性。
